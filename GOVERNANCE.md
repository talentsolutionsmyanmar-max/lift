# Governance

Lift is maintained and owned by **Talent Resources Myanmar Co.,Ltd**, Yangon,
Myanmar. The company site is [www.refertrm.com](https://www.refertrm.com/).

Lift is released under the MIT Licence. See [LICENSE](LICENSE).

## Decision process

This is a small project. There is no separate board or working group in this
repository.

- Talent Resources Myanmar Co.,Ltd is the owner and has the final say on
  licence, product direction, releases, and what is published.
- Maintainers named on this GitHub repository review issues and pull requests.
- A change lands when a maintainer accepts it. Tests in `npm test` should pass.
- Obvious documentation or test-only fixes can be merged after a short review.
- Product, privacy, health-guidance, or experimental-backend changes need an
  explicit maintainer decision.
- Maintainers may decline, request changes, or revert work that conflicts with
  dignity, privacy, or the current research-and-review scope.

Conduct reports follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Security
reports follow [SECURITY.md](SECURITY.md).

## Contributors

Anyone may open an issue or pull request under [CONTRIBUTING.md](CONTRIBUTING.md).
Contributing does not transfer ownership of Lift and does not create an
employment, partnership, or service relationship.
