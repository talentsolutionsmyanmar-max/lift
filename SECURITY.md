# Security

Please report vulnerabilities in Lift privately. Do not open a public GitHub
issue, pull request, or discussion for a security report.

## How to report

Use GitHub Security Advisories for this repository:

https://github.com/talentsolutionsmyanmar-max/lift/security/advisories/new

On the repository **Security** tab, choose **Report a vulnerability** and
describe the issue. GitHub keeps that report private until maintainers publish
an advisory.

There is no security-contact email in this repository.

## What to include

- What is affected (path, route, or client file)
- What you expected and what happened
- Steps to reproduce, with invented examples only
- Impact, as you understand it
- Any suggested fix, if you have one

Do not include real participant data, credentials, or live receipt codes.

## Scope

This repository is a research and design-review snapshot. The published team
test does not deploy the experimental backend. Still report issues in:

- Static files in `dist/` and team-test artifacts
- Experimental routes in `api/` and logic in `lib/`
- Build and test scripts

Hosting, DNS, and accounts outside this repository are out of scope unless they
are required to reproduce a defect in this code.

## After you report

Maintainers at Talent Resources Myanmar Co.,Ltd will review the advisory and
decide whether to patch, publish, or decline it. There is no paid bounty
programme described in this repository.
